VOX DOC: make Vox-style documentary videos on any topic with Antigravity

Before this, set up Flow Connector: open the extension's side panel,
Setup -> Copy setup prompt, and paste that into Antigravity.

Then do ONE of these:

  A) Unzip this file, open the unzipped folder in Antigravity (or in VS Code
     with Antigravity), and type:   start

  B) In any Antigravity chat, type:
       vox-doc.zip is in my Downloads folder. Unzip it, read GEMINI.md inside and follow it.
     If the zip is somewhere else, give its full path instead (Windows:
     right-click the file -> "Copy as path"), or drag the file into the chat
     box, which inserts its path.

Antigravity installs everything, sets up the tools step by step, and then makes
your video. Afterwards it works from ANY chat:
    vox doc start        a new video
    vox doc continue     carry on where you stopped

(Antigravity: read GEMINI.md in this folder and follow it.)
